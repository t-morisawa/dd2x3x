FAQ

Bluesky FAQ

What "decentralized" actually means, part by part.

Are AT Protocol and Bluesky the same?

No. AT Protocol is the protocol that supports data ownership. Bluesky is a social network built on it, and Bluesky the company also runs infrastructure such as the Relay.

Isn't the Relay centralized?

Yes. The Relay is an aggregator. Data ownership comes first; elsewhere the design balances it with usability.

What about account censorship?

Depending on a single company is a risk. Handing account management to a third-party body would reduce that dependence.

How do they make money without owning the data?

Social media should shift from an ad business to public infrastructure. Paid plans and royalties from third-party apps are revenue sources too, aiming for profits that reach users, developers, and operators.

Go iterators

range over func fits WebSocket connection management

Wrap connecting and receiving events in an iterator so the caller can focus on handling events.

Iterator side

Manages the WebSocket connection

Handles connecting, receiving events, and cleanup.

func (c *Client) Seq(ctx) iter.Seq2[Msg, error] {
  return func(yield func(Msg, error) bool) {
    conn := dial(ctx)   // connect
    defer conn.Close()  // clean up
    for {
      if !yield(conn.Read()) { return }  // receive
    }
  }
}
Handler side

Handles events with for range

No need to think about the connection. Just handle each event as it arrives.

for msg, err := range client.Seq(ctx) {
  handle(msg)
}
Another Go feature: when the loop hits break, the iterator's defer reliably cleans up.
