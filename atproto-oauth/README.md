# AT Protocol OAuth Flow Lab

AT Protocol OAuthの流れを段階的に確認する、ブラウザだけで動く学習用シミュレーターです。

## 起動方法

このフォルダーで簡易HTTPサーバーを起動し、表示されたURLをブラウザで開きます。

```sh
python3 -m http.server 8000
```

## できること

- ハンドル解決からDPoP Nonce再試行まで、全9ステップを前後・自動再生
- コンポーネント間の通信、HTTPリクエスト／レスポンス、暗号情報、DB状態を確認
- PKCEの値とP-256公開鍵をブラウザのWeb Crypto APIで生成
- 4問の理解度チェック

## 注意

学習用のデモです。AT Protocolサーバーへの通信、実アカウントの認証、トークン発行、秘密鍵の安全な永続化は行いません。画面上のエンドポイントやHTTPレスポンスは説明用の例です。
